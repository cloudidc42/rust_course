# หลักสูตร Rust ฉบับสมบูรณ์ — จากพื้นฐานสู่ระดับโลก

ยินดีต้อนรับสู่หลักสูตรการเขียนโปรแกรมและพัฒนาเว็บแอปพลิเคชันด้วยภาษา **Rust** แบบครบวงจร
ออกแบบมาให้เรียนได้ตั้งแต่ **ไม่มีพื้นฐานเลย** ไปจนถึงระดับ **มืออาชีพและระดับโลก (World-Class Professional)**

หลักสูตรนี้แบ่งเป็น **110 Part** (และจะขยายเพิ่มเรื่อย ๆ) แต่ละ Part มีเนื้อหาที่ใช้งานได้จริง
พร้อมโค้ดตัวอย่างที่รันได้จริง คำอธิบายละเอียด แบบฝึกหัด และสรุปท้ายบท

## วิธีใช้หลักสูตรนี้

- อ่านตามลำดับ Part 1 → 110 เพราะเนื้อหาถูกออกแบบให้ต่อเนื่องกัน (แต่ละบทอ้างอิงความรู้จากบทก่อนหน้า)
- ทุกโค้ดตัวอย่างสามารถ copy ไปรันได้จริงด้วย `cargo run` (ต้องติดตั้ง Rust toolchain ก่อน ดู Part 1)
- มีแบบฝึกหัดท้ายบททุก Part ควรลงมือทำก่อนไป Part ถัดไป
- ไฟล์เนื้อหาทั้งหมดอยู่ในโฟลเดอร์ [`parts/`](./parts)
- ดูสารบัญฉบับเต็มพร้อมคำอธิบายรายบทได้ที่ [`docs/curriculum.md`](./docs/curriculum.md)
- แนวทางการเขียน/มาตรฐานเนื้อหาของหลักสูตรอยู่ที่ [`docs/STYLE_GUIDE.md`](./docs/STYLE_GUIDE.md)

## โครงสร้างหลักสูตร (6 โมดูลใหญ่)

| โมดูล | ชื่อ | Part | สถานะ |
|---|---|---|---|
| 0 | เริ่มต้นใช้งาน Rust (Getting Started) | 1–5 | ✅ เสร็จสมบูรณ์ |
| 1 | พื้นฐานภาษา Rust (Core Language Fundamentals) | 6–20 | ✅ เสร็จสมบูรณ์ |
| 2 | ระดับกลาง (Intermediate) | 21–40 | ✅ เสร็จสมบูรณ์ |
| 3 | ระดับสูง (Advanced) | 41–60 | ✅ เสร็จสมบูรณ์ |
| 4 | การพัฒนาเว็บแอปพลิเคชัน (Web Development) | 61–85 | ✅ เสร็จสมบูรณ์ |
| 5 | Full-Stack และ WebAssembly | 86–95 | ✅ เสร็จสมบูรณ์ |
| 6 | Production, DevOps และระดับมืออาชีพ | 96–110 | 🚧 กำลังเขียน |

ดูรายชื่อ Part ทั้งหมดแบบละเอียดที่ [`docs/curriculum.md`](./docs/curriculum.md)
